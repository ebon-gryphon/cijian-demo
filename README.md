# 此间 · 我们的关系空间

这是一个根据「双方对自己和彼此的认识 → 关系知识库 → 忙碌时代理接待」构想制作的中文交互 Demo。以异地情侣林屿与许知夏作为虚构示例。

## 一键下载体验

当前工作区包含 v0.4.0 的本地更新；以下链接指向最近一次对外发布，可能仍是旧版。

**[下载 Demo 体验包（ZIP）](https://github.com/ebon-gryphon/cijian-demo/releases/latest/download/cijian-demo.zip)** · [查看版本与附件](https://github.com/ebon-gryphon/cijian-demo/releases/latest)

1. 点击上方下载链接，保存 `cijian-demo.zip`（无需登录 GitHub）。
2. 解压整个压缩包，打开 `cijian-demo` 文件夹。
3. 双击 **index.html**，用 Chrome、Edge 或 Safari 开始体验。

无需安装 Node.js、运行命令或填写 API Key。推荐在电脑浏览器体验；手机的文件预览器不一定能运行交互页面。不要直接在压缩包内打开文件。

普通体验者选择 `cijian-demo.zip`，无需下载 GitHub 自动生成的 `Source code` 源码包。如果下载未开始，可进入版本页面，在 **Assets** 中选择体验包。

体验包仅包含 `index.html` 和 `README.txt`。也可以在版本页面直接下载 `index.html`，保存到电脑后用浏览器打开；GitHub 文件预览页面不会运行 Demo。

## 已有源码时打开体验

直接双击本文件夹中的 **打开此间.html**。不需要启动服务，不需要 API Key；页面运行时不调用云端模型。请用 Safari、Chrome 或 Edge 打开。如果系统预览只显示代码，右键选择浏览器打开。

数据仅保存在当前浏览器的本机存储中。浏览器不允许保存时仍可体验，但刷新后可能恢复示例。单文件版本和本地开发预览的存储相互独立。切换身份是演示操作，不是真实账号鉴权。

## v0.4.0 更新

“回来接着聊”现为“待你回应”，只收录 AI 未能回答的部分，关系决定、情绪感受优先展示。已答清楚的内容不重复列入，未经 AI 接待的普通留言也不进入这份列表。

助手功能已融入聊天框标题栏，只保留“我的助手”开关与接待设置图标。侧栏去掉双人姓名、装饰文案和单独滚动；左下角头像菜单保留登录 / 账号和设置。切换体验身份使用页面右上方的按钮。登录弹窗明确真实账号登录尚未开放。

私人记忆空间、收藏、回忆纪念模式，以及聊天中的欢迎回来提示已移除。新建记忆双方可见，关于对方或共同经历的内容仍需对方确认后才供助手引用。

## 建议体验顺序

1. 在默认许知夏视角发送“你几点忙完？今天有点委屈。晚饭吃什么？”。
2. AI 回答已知忙碌时间，其他片段留给本人。
3. 点击页面右上方“切换为林屿”，进入“待你回应”。已答的忙碌时间不在列表中；情绪片段优先，晚饭问题随后。可以展开原消息和 AI 回复。
4. 点击“回应这些内容”亲自回复，对话同步更新、待办关闭。已经线下回复时，可点“已当面回应”。
5. 在“彼此的模样”回应对方的理解，或到“共同记忆”写一条愿意分享的信息。关于对方和共同经历的记忆，需要另一方确认；不符合或暂缓的内容不参与接待。
6. 在聊天框标题栏的开关或接待设置中控制自己的助手；状态仍支持在线、手动忙碌和离开两分钟后自动接待。

## 演示边界与旧数据

这是同机交互原型，未答片段按标点分句并由关键词规则识别，没有真实模型、双人鉴权、跨设备同步或微信代发。AI 不能做完整语义理解。助手关闭或未进入接待状态时，来信仅留在对话，不会被误计为“AI 未答”。

原路径、原浏览器中的旧聊天和共同记忆可继续读取。旧版私人记忆保留在原存储，但不再展示、参与回复或自动变成共享内容；旧收藏存储不再读取。本次功能移除不会清空旧版本机数据。

引用面板仍显示记忆当前版本，历史对话不会随记忆更新而改写。忙碌状态依据页面可见性与窗口焦点；返回页面暂停自动接待，手动忙碌需主动接回。关闭页面后不能持续接待。请勿将这个版本当成真实消息服务或输入真实秘密。

历史说明见 [v0.3.0](docs/release-v0.3.0.md) 和 [v0.2.0](docs/release-v0.2.0.md)，以本节当前能力为准。

## 源码开发

Node.js 22.13+（建议 24）。下载或克隆源码后，在本文件夹运行 `npm ci`，再运行 `npm run dev`，打开终端显示的本地地址。

- `app/page.tsx`：界面、记忆管理、身份切换、消息交接。
- `app/demo.ts`：数据结构、示例数据和接待规则。
- `app/presence.ts`：自动状态、手动覆盖与页面事件监听。
- `app/globals.css`：视觉样式和响应式布局。
- `scripts/build-offline.mjs`：打包单文件离线版本。
- `tests/reception.test.mjs`：接待证据与隐私规则测试。
- `tests/interaction.test.mjs`：理解回应、身份命名、状态边界与事件测试。
- `tests/handoff.test.mjs`：未答片段、优先级、处理完成、旧消息关联和持久化恢复测试。

验证与打包：`npx tsc --noEmit`、`node --test tests/*.test.mjs`、`npm run build`、`node scripts/build-offline.mjs`。

页面还在支持 WebMCP 的环境提供读取演示状态、发送演示消息的接口。未进行浏览器端 WebMCP 实测，不影响常规网页操作。

## 制作下载包

修改界面后，先运行 `npm run build` 和 `node scripts/build-offline.mjs` 更新离线页面，再运行 `python3 scripts/package-release.py`（需要 Python 3）。仅重新打包现有离线页面时，可直接运行最后一条命令。

脚本会在 `.releases/` 生成 `cijian-demo.zip`、单独的 `index.html` 和 `SHA256SUMS.txt`。发布 GitHub Release 时上传这三个附件；此目录不会提交进源码。体验包不包含依赖、环境变量、本机缓存或用户的浏览器聊天记录。
