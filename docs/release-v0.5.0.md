# v0.5.0 · 真实模型接待、口吻学习与记忆附件

- 网页版新增 OpenAI、DeepSeek 和安全自定义 Chat Completions 接口；离线版和未配置模型时继续使用基础规则接待。
- 模型可回答普通日常话题，关系承诺、决定、感情表态和缺失的个人事实仍交回本人。请求和结果均校验结构、引用与明确越界表达。
- 新增“我的说话方式”，只学习功能开启后的本人新消息；可关闭、逐条删除或全部清除，不会回读旧聊天。
- AI 消息新增“这句不像我”修正入口，后续接待优先参考本人修正，不改写历史消息。
- API Key 不再写入 `localStorage`，仅保留在当前标签页会话；切换服务时会清空待保存密钥。
- 共同记忆可添加图片和普通文件，图片可预览，文件可打开或下载。不支持视频；每条记忆最多 6 个附件，单个不超过 100 MB。
- 切换身份、本人接回、关闭接待或修改模型、口吻、共同记忆时，会取消在途回复，避免旧结果追加到当前会话。

本版仍是同机交互 Demo，尚无双人账号隔离、跨设备同步或服务端密钥保管。附件和口吻数据仅保存在当前浏览器。
