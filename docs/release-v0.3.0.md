## 下载即用

下载 Assets 中的 **cijian-demo.zip**，解压后双击 **index.html**。无需安装、账号或 API Key。

## 本次优化

- **私有收藏**：在对方本人消息下点击「记住这句话」。原话与私人备注分开保存，侧栏「我的收藏」可查看、编辑备注、回到原对话、移除与撤销最近一次移除。收藏不通知对方，不需要确认，没有共享入口，也不供接待助手引用。
- **更安静的状态栏**：只显示在线、忙碌或暂时离开。点击自己的状态即可选择，忙碌时保留「接回对话」。移除了手动／自动来源和顶部常驻规则说明，后台的两分钟离开与返回暂停逻辑保持不变。

收藏内容、数量和提醒按当前演示身份隔离。原消息有时间时一并保存；旧消息未记录时间时如实标注。助手生成的消息和自己的消息不能收藏。

附件包含体验 ZIP、独立 `index.html` 与 `SHA256SUMS.txt`。兼容读取原路径、原浏览器中的旧版记忆和聊天。

**演示边界**：这是同机规则模拟，没有真实双人账号鉴权或加密存储。能操作本机和切换体验身份的人仍可访问演示数据，请勿保存真实秘密。关闭页面后不能继续接待，当前也没有跨设备同步。
