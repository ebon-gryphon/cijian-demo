# 此间：双人日记与可定制形象

调研日期：2026-09-12。依据官网及开发者应用商店介绍，未进行完整付费实测，不据此推断留存、营收或市场空白。

## 判断

双人日记加可定制小人适合收敛成一个可测试的原型，但功能组合本身还不足以证明差异化。应先验证一个具体假设：一方愿意记录、另一方不爱长篇表达时，一句话、心情和自己的形象是否能让两个人持续参与同一本日记。

以上资料没有证明所有竞品都缺少“历史装扮快照”，因此不把它描述为独家能力。

## 本次原型

同一件小事保留两个人分别写下的段落，各自只能修改自己的表达；心情与装扮随记录保存，之后换装不会改变旧日记。二维小人支持发型、发色、肤色、衣服、颜色和配饰。

范围限定为日记和装扮两个入口，不扩展商城、宠物养成或AI分身。使用虚构示例、同机切换身份、浏览器本地存储；没有跨设备同步。

## 接下来验证什么

先邀请5对情侣使用7天；这是定性试验规模建议，不是行业基准。特别招募一方爱记录、另一方不爱写作的组合。

观察双方是否都主动参与，是否在没有催促时再次记录，是否会回看共同写过的页面。访谈区分“喜欢小人”与“因此愿意记录”。可用可点击原型或主持人辅助流程，当前单机Demo不能直接测量异地双设备的真实留存。

如果用户只换装却不写日记，就需要重新判断小人和记录之间的关系；不能用换装点击量代替痛点得到解决。
