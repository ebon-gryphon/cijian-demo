## 下载即用

下载下方 Assets 中的 **cijian-demo.zip**，解压后双击 **index.html**。无需安装、登录或 API Key。

## 根据体验反馈更新

- **理解可以不同意**：支持「这符合我的理解」「不太符合」「稍后再说」。否定理由可留空，双方原话与回应保留；分歧和暂缓内容不供助手引用，作者修改后重新确认。
- **姓名（助手）**：回复改为「林屿（助手）」或「许知夏（助手）」，头像增加助手角标，语气更自然，依然明确区别于本人。
- **自动状态＋手动接回**：离开页面或窗口 2 分钟后才允许接待新消息，返回立即暂停；手动忙碌在返回后保留，点击接回或本人发送消息后解除。状态按钮放在聊天顶部，助手权限由双方各自设置。

默认林屿为手动忙碌，方便立即体验。可切换体验身份模拟双方离开与返回；返回不会自动处理留言。

## 附件

- `cijian-demo.zip`：推荐下载，包含离线页面与中文使用说明。
- `index.html`：单独的离线体验页面。
- `SHA256SUMS.txt`：下载文件校验值。

这是规则模拟的单机交互 Demo，未接入真实大模型或双人消息服务。关闭页面后不能继续接待，后台页面可能被浏览器暂停；不要在多个标签页同时操作或输入真实敏感信息。使用原浏览器和原文件位置时兼容旧记录，新路径可能使用独立存储。
