离线交互 Demo / v0.2.0

如何打开
1. 先解压 cijian-demo.zip，进入 cijian-demo 文件夹。
2. 双击 index.html，用 Chrome、Edge 或 Safari 打开。
3. 如果显示代码或空白预览，请右键文件，选择“打开方式”中的浏览器。

不用安装程序，不用启动服务，不需要 API Key。
建议在电脑浏览器体验，手机文件预览器可能不支持交互页面。

三分钟体验
1. 在默认聊天中点击“你几点忙完？”，查看回复及记忆来源。
2. 点击“今天有点委屈”，查看如何把留言交给本人回应。
3. 打开“彼此的模样”，对“你眼中的我”的理解选择符合、不太符合或稍后再说。
4. 在“共同记忆”添加信息，体验私人/共享设置及另一方确认。
5. 切换为林屿，进入“回来接着聊”，点击“我回来了”并亲自回复。

自动状态与助手
聊天顶部自己头像旁可“设为忙碌”或“接回”，助手发送者显示为“姓名（助手）”。
自动模式下，切到其他标签页或窗口 2 分钟后才允许接待新消息，返回立即暂停。
手动忙碌时，短暂返回不会解除；点击“接回”或本人发送消息后恢复自动模式。
每个人的“允许我的助手接待”开关独立，关闭后只收留言不代回。
单机切换体验身份也会使原身份开始离开计时。可切换后等 2 分钟，再发消息观察对方助手接待。
默认林屿手动忙碌，便于第一次打开即体验回复。

重要说明
这是虚构人物的交互原型，回复由关键词和规则模拟，未接入真实大模型。
双方身份切换仅用于演示，没有真实账号鉴权，也不会向另一台设备或微信发送消息。
数据只保存在当前浏览器本机，建议不要输入真实敏感信息。
换浏览器、移动文件、清理浏览器数据或浏览器禁止存储时，记录可能无法保留。
关闭页面后不能继续接待；后台页面也可能被浏览器暂停。没有跨设备或多标签页同步。
保持原文件路径与浏览器，可兼容读取旧版记录；更新前建议保留原文件。
回忆纪念模式是远期概念演示，不能与真实逝者交流。

获取更新
https://github.com/ebon-gryphon/cijian-demo/releases/latest
公开下载，无需登录 GitHub。请在版本页面的 Assets 中选择 cijian-demo.zip。

文件校验
版本页面的 SHA256SUMS.txt 提供下载附件的 SHA-256 校验值。
Mac 可使用 shasum -a 256 cijian-demo.zip；Windows PowerShell 可使用
Get-FileHash .\cijian-demo.zip -Algorithm SHA256。
