离线交互 Demo / v0.4.0

如何打开
1. 解压 cijian-demo.zip，进入 cijian-demo 文件夹。
2. 双击 index.html，用 Chrome、Edge 或 Safari 打开。
3. 如果显示代码，请右键文件，选择浏览器打开。

不用安装程序，不用启动服务，不需要 API Key。
建议在电脑浏览器体验，手机文件预览器可能不支持交互页面。

三分钟体验
1. 默认是许知夏视角，林屿忙碌。发送“你几点忙完？今天有点委屈。晚饭吃什么？”。
2. AI 回答已知的忙碌时间，其余部分留给本人。
3. 点击页面右上方“切换为林屿”，再打开“待你回应”。
4. 列表只展示未答部分，关系与感受优先；原消息和 AI 回复可以展开查看。
5. 点击“回应这些内容”，回复会回到同一对话，同时关闭对应待办。已在其他场合回应时，可以标记“已当面回应”。
6. 到“共同记忆”添加愿意分享的信息。关于对方或共同经历的内容，需要另一方确认后，AI 才会引用。

页面调整
助手功能已融入聊天框标题栏，仅保留“我的助手”开关与接待设置图标。
私人记忆空间、收藏、回忆纪念模式，以及欢迎回来提示已经移除。
左侧导航去掉双人姓名与底部装饰文案，头像菜单保留账号入口和设置，删除切换身份。身份切换使用页面右上方已有的按钮。
“登录 / 账号”目前可选择演示身份；真实账号登录尚未开放。

助手状态
点击聊天顶部自己的“在线 / 忙碌”选择状态，忙碌时可接回对话。
自动模式下，离开页面两分钟后允许助手接待新消息，返回立即暂停。
手动忙碌时，返回不会解除；点击接回或本人发送消息后恢复在线。
每个人的助手开关独立，关闭后收到的普通消息不会记为“AI 未答”任务。

旧版记录
原路径、原浏览器中的聊天与共同记忆继续读取。
旧版私人记忆不再展示或被助手使用，也不会自动变成共享记忆。
旧收藏存储不再读取。本次移除功能不会清空旧版本机数据。

演示边界
虚构人物、规则模拟，没有真实模型、账号鉴权、跨设备同步或微信代发。
未答片段按标点分句并由规则判断，不能等同真实语义理解。
数据保存在当前浏览器；换浏览器、移动文件或清理存储可能导致记录无法读取。
关闭页面后不能持续接待。请勿输入真实秘密。

文件校验
SHA256SUMS.txt 提供附件的 SHA-256 校验值。
