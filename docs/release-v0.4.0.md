## v0.4.0 · 未答内容与界面精简

- “回来接着聊”更名为“待你回应”，只收录助手未能回答的消息片段，关系决定、情绪感受优先展示。AI 已答清楚的事实和未经过 AI 接待的普通消息不进入此列表。
- 每条待办保留可展开的原消息与 AI 回复；本人回复进入同一对话并关闭待办，也可标记已当面回应。旧版紧邻的 AI 回复会与原消息建立关联。
- 助手功能融入聊天框标题栏，仅保留“我的助手”开关和接待设置图标，移除独立区块的标题、说明与状态标签。双方开关仍各自独立。
- 移除私人记忆、收藏入口及其功能；新记忆明确双方可见，关于对方或共同经历仍需对方确认。
- 移除侧栏装饰文案、双人姓名、回忆纪念模式和聊天欢迎回来提醒。侧栏内容不再单独滚动。
- 左下角改为紧凑头像菜单，保留登录 / 账号和设置，移除切换身份。切换演示身份使用页面右上方已有的按钮。真实账号登录尚未接入。

本版本保留原本机数据，但不再读取收藏、展示私人记忆或将其自动共享。已删除的收藏源码可从 Git 历史恢复。

本地交互仍为关键词与分句规则模拟。打包的 HTML 可直接用浏览器打开；没有新增云端服务。
