# v0.6.0 · 互动封面、双人小游戏与记忆碎片

发布日期为 2026-09-09。本版包含今天更新的双人空间体验。

## 下载体验

下载附件 `cijian-demo.zip`，解压后打开 `cijian-demo/index.html`。也可以直接下载附件 `index.html`，用电脑浏览器打开。无需安装依赖或填写 API Key。

## 今天的更新

- 新增双人手记封面，支持水波互动、点亮爱心和进入空间的过渡效果；可从账号菜单返回封面。
- 新增“猜你会怎么选”小游戏，提供 8 个问题。两人分别选择自己的答案并猜对方，双方提交后才揭晓；揭晓前可修改自己的答案，历史结果可回看。
- 游戏结果可带入聊天继续交流，或整理为待补充、确认的共同记忆。
- 新增“记忆碎片”，翻阅已确认的共同记忆，也可隐藏内容、只显示标语；按演示身份分别保存显示偏好。
- 更新聊天与共同记忆等页面布局，增加手机底部导航，调整恢复聊天记录与切换身份时的滚动定位。

## 相比 v0.5.0 的其他更新

源码增加 `/online` 联机测试入口，支持邀请码加入双人空间、服务端保存消息与跨设备同步。网页端可使用模型接待；需要相应的服务端配置。

## 体验范围

本 Release 的 HTML 与 ZIP 是本机离线 Demo，通过切换演示身份完成双人互动。聊天、共同记忆和游戏答案保存在当前浏览器中，离线包使用基础规则接待。联机测试与真实模型调用需运行网页服务端。

附件 `SHA256SUMS.txt` 提供 ZIP 和 HTML 文件的 SHA-256 校验值。
