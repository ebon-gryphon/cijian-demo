# 美好记忆示例配图

2026年9月14日重新制作三篇虚构示例及三张原创 AI 配图。

- `public/memories/first-sea.jpg` 对应《第一次一起看海》，晴朗海边牵手踩浪花。
- `public/memories/birthday-flowers.jpg` 对应《生日那晚，你把花藏在身后》，鲜花、蛋糕与生日惊喜。
- `public/memories/first-home.jpg` 对应《搬进新家的第一束阳光》，两人在新家窗边安放绿植。

图片由内置 imagegen 生成，原图为 1536 × 1024 PNG，网站使用 JPEG 发布副本。配图需求记录在 `memory-photo-prompts.json`。这些内容均为明确标注的演示故事和 AI 配图。

首页展示与示例列表只引用这组三张新图。历史图片仅用于兼容用户已修改或保存的旧记录，不再作为推荐示例。新离线文件内嵌配图。

旧版原始演示条目按完整内容的 SHA-256 指纹退休，本机记录与草稿会清理未修改的旧示例，云端列表也会排除这些条目。修改过的故事、素材或上传图片不匹配原始指纹，继续保留。旧版自动导入逻辑已移除。
