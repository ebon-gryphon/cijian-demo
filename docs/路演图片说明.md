# 路演回忆配图

2026年9月10日新增三张 AI 生成的虚构情侣回忆配图，用内置 image_gen 工具生成，供林屿与许知夏的演示故事使用。不是用户真实照片。

- `public/memories/west-lake.jpg` · 把黄昏多留一会儿
- `public/memories/weekend-breakfast.jpg` · 不用赶时间的早晨
- `public/memories/rainy-noodles.jpg` · 下雨天的那碗面

打开“共同记忆”，照片记忆优先显示，点击照片可放大。网页图片随站点提供，单文件离线版本内嵌三张照片，无需联网加载。现有浏览器只迁移一次示例内容，不覆盖已经修改的面馆记忆，也不恢复之后删除的照片。

图片采用 JPEG 发布副本以降低路演包大小，原始生成文件仍保留。完整提示词保存在 `memory-photo-prompts.json`。
